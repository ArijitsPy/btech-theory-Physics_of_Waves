## Setting up the Google Form (one-time, for future-me)

1. Create a Google Form → add a **File upload** question → restrict to PDF, one file.
2. Under Settings, restrict to accounts in your organisation if you want submissions tied to institute email.
3. Click **Send** → the `<>` embed icon → copy the `src` URL and paste it into the `iframe` above.

## Setting up GitHub Classroom (one-time)

1. Go to [classroom.github.com](https://classroom.github.com) and create an organization for the course if you haven't already.
2. Create a new assignment, link the course repository as a template if you're distributing starter code.
3. Copy the invite link it generates and paste it in place of the placeholder link above.
