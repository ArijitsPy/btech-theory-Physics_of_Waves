## How I add a new tutorial sheet (for future-me)

1. Drop the PDF into `assets/materials/` in the repo, e.g. `tut3.pdf`.
2. Add a new `## Tutorial N` section above with a link: `[Download Tutorial N questions (PDF)](/assets/materials/tutN.pdf)`.
3. Commit and push — the site rebuilds automatically via GitHub Actions.
