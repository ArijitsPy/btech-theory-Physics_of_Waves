## Alternative: embedded restricted Google Sheet

If you'd rather maintain marks in a live spreadsheet instead of editing this Markdown table each time:

1. Create a Google Sheet with the marks.
2. **Share → Restricted** → add access only for your institute domain (e.g. `@iitkgp.ac.in`), so only logged-in students can view it.
3. **File → Share → Publish to web** is **not** what you want here — that makes it public. Use a direct restricted share link instead, or embed via `<iframe>` pointing to the sheet's published (domain-restricted) URL.

```html
<iframe
  src="https://docs.google.com/spreadsheets/d/REPLACE-WITH-SHEET-ID/pubhtml?widget=true&headers=false"
  width="100%" height="500" frameborder="0">
</iframe>
```

{: .important }
> Never put roll numbers or names in this repository, even temporarily — GitHub history keeps every past version, and the repo is public. Keep the Secret ID → roll number mapping in a private, non-repo spreadsheet only you can access.
